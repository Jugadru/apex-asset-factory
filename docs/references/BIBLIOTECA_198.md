VSE: simular BOX agora, estender ou conservar a partir de observações limitadas, pneus, clima incerto e tráfego. Comparar heurística determinística e Monte Carlo antes de redes neurais. A qualidade do STAFF deve influenciar a informação e a recomendação, não conceder velocidade fictícia. FL-MANE para comportamento e rádio; Pitwall para aposentadorias e temporadas; Grand Prix Universe para módulos configuráveis; Race Game para editor. WORKS para fluxo material; The Undercut para categorias em paralelo; Delta para corrida contínua; Team Principal para sandbox. Grand Prix World/F1 Manager Professional para fornecedores, política, contratos, reservas e conselho. Não confundir modelos científicos com telemetria da F1 2012.
