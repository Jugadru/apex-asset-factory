# v0.3.0 — Material & Texture Factory (first scoped candidate)

Opt-in postprocess of a hash-pinned, original schema 7/8 staged vehicle. No source overwrite, no change to mesh accessors, transforms, UVs, geometry bytes or material names. Original deterministic procedural RGB PNGs: base-color modulation (original color factor retained) and glTF packed roughness G / metallic B; R unused (not AO). 256 or 512 px allowed, source texture cap and GLB byte limit enforced. Tile repeat sampler, no external files, no texture downloads or third-party assets. Paint grain refined after actual capture. Carbon weave, rubber grain and brushed-metal pattern are visual approximations, not measured physical materials. Native Blender and Godot check actual imported texture links and resolution; Godot checks channel assignment. Exact canonical regeneration checks for output tampering; this is not a general validator for arbitrary textured GLBs. The legacy validator still rejects textures.

```sh
PYTHONPATH="$PWD/tools" python3 -m asset_factory.stage_pbr /tmp/original-build --source-sha256 <exact-source-sha256> --blender /absolute/path/blender --godot /absolute/path/godot --workspace /tmp/new-pbr --size 256 --capture
```

The supported entry point checks source request and local receipt; local receipts are not signed authorization. The low-level material generator is only a deterministic transformation helper. No change to existing LOD/build or primary registry/promotion behavior. PBR output must remain isolated: registry support for textured variants and reviewed distribution are not implemented. UV audit counts zero-area texture triangles (threshold 1e-12); it does not repair or certify UVs, seams, overlap, texel density or baking. Normal maps, UV repair, tangent validation, baking, AO, physically calibrated materials, artist approval and production use are pending. Native test scope: 256 px; 512 px synthetic map test only. No game integration or GPU/FPS claim. No automatic merge.
